## Project Overview

This project simulates a real-world e-commerce business analysis scenario using Amazon sales data.

The objective is to analyze sales performance, product categories, order fulfillment, and monthly revenue trends through SQL queries and Tableau dashboards.

The analysis aims to demonstrate how data can support business decisions and improve operational efficiency.
